# Security policy

This project controls a physical water valve, so please report a problem privately rather than in a public issue.

Use GitHub's private reporting: **Security** tab, then **Report a vulnerability**. You will get a reply within a few days.

Only the latest release and `main` are supported.

Things that are in scope: a way to open the valve, read its credentials or reach the API without passing Cloudflare Access,
or to get around the Google Home account-linking password. How the project is protected is described in
[docs/ci-and-github.md](docs/ci-and-github.md).
